# 용어 사전 (표준 번역 고정)

표준 용어가 아닌 번역을 임의로 만들지 않기 위한 고정 사전. 영어 기술 용어나 개념을 한국어로 쓸 때 이 표를 먼저 본다. 표에 없고 표준 용어가 불확실하면, 임의 번역 대신 영어를 병기하거나 사용자에게 확인한다.

| 개념 / 영어 | 쓸 용어 | 쓰지 말 것 | 메모 |
|---|---|---|---|
| log level, verbosity | 로그 레벨 | 상세도 | `--log-level`이 조절하는 값 (2026-08-05) |
| repository | Git 레포지토리 | 저장소(단독) | "문서 저장소"는 보관함으로도 읽혀 모호. 기존 게시글은 "저장소", 신규 글은 "레포지토리" (블로그 전체 통일은 미정) |
| declaration site | 선언 위치 | 정의 한 건 | 조어 금지, 현상 직접 서술 |
| cross-file reference | 크로스파일 참조 | | 확립됨 |
| warmup (indexing) | 워밍업 | | 인덱싱 완료 전 상태 |
| language server | 언어 서버 | | |
| project model | 프로젝트 모델 | | |
| root marker | root marker | 루트 표식 | 영어 유지 |
| bug report (from users/QA) | 리포팅 | 제보, 보고 | 사용자 확정 (2026-08-14). 음차지만 실무 관용으로 채택 |

## 원칙

- 표에 없는 용어는 **임의로 번역하지 않는다.** 표준 용어를 확인(공식 문서, 커뮤니티 관용)한 뒤 표에 추가한다.
- 확인 못 하면 **영어 병기**("로그 레벨(log level)") 또는 사용자 확인.
- 새 용어가 확정될 때마다 이 표에 한 줄 추가한다. 이 파일이 단일 출처다.
- 벡터 DB는 쓰지 않는다. 용어는 정확 매핑이라 큐레이션된 이 표가 맞다.
