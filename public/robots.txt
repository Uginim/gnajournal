# Cloudflare 가 AI 크롤러 차단 목록이 담긴 robots.txt 를 이 파일 "앞에" 붙여서 내보낸다.
# 그래서 여기에 차단 규칙을 다시 적으면 같은 내용이 두 벌 나온다. 중복은 동작에 문제를
# 일으키지 않지만 읽기 나쁘므로, 관리형 파일에 없는 것만 여기 둔다.
#
# 관리형 파일이 차단하는 대상: Amazonbot, Applebot-Extended, Bytespider, CCBot,
# ClaudeBot, CloudflareBrowserRenderingCrawler, Google-Extended, GPTBot,
# meta-externalagent. 전부 AI 학습용 크롤러라 검색 노출이나 광고 심사와 무관하다.
# 애드센스 크롤러는 Mediapartners-Google, 검색 크롤러는 Googlebot 이며 둘 다 허용된다.
#
# 주의: Cloudflare 대시보드에서 관리형 robots.txt 를 끄면 위 차단이 사라진다.
# 그때는 이 파일에 차단 규칙을 직접 옮겨 적어야 한다.
#
# 아래 Sitemap 지시자가 이 파일을 두는 이유다. 관리형 파일에는 사이트맵 위치가 없어서
# 크롤러가 robots.txt 만으로는 sitemap 을 찾지 못했다.
# Astro 의 sitemap 통합은 sitemap-index.xml 을 만든다(/sitemap.xml 이 아니다).
